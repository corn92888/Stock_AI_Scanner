# 盤中研究協議

當使用者說「跑一次盤中」時，必須先完成本流程，再給股票結論。核心目標不是找今天盤中最會衝的股票，而是找「今天買進後，明天到未來幾天仍有續漲理由」的標的。

## 固定七點

1. 資料正確性
   - 先確認本機時間、台北時間、資料庫最新 `scan_runs`、報表檔名、報表產生時間。
   - 若發現抓到舊報表、舊價格或非今日資料，必須停止使用該結果，重新執行掃描。
   - 盤中價格至少要用即時報價或可靠行情來源抽查主要候選股。

2. 原始三策略保留
   - 保留並列出三類候選池：
     - 順勢噴出 / 順勢突破
     - 逆勢抄底 / 低檔爆量
     - 波段敘事 / 波段蓄勢
   - Telegram 與最終報告都必須保留三類，不可以只剩一段主觀分析。

3. 技術面不是唯一依據
   - 程式分數只能當第一層篩選。
   - 後續必須加入成交值、量比、漲跌幅、日內位置、產業熱度、籌碼、基本面、新聞催化與隔日續漲可能性。
   - 小成交值、冷門股、只靠量比但沒有主線支撐者，要降級。

4. 國際視野與即時新聞
   - 必須查台股盤中新聞、台股族群新聞、美股/費半/那斯達克、AI、半導體、記憶體、油價、美元利率與重大地緣政治事件。
   - 必須查本週重大市場事件日曆，例如 COMPUTEX、NVIDIA GTC、法說會、除權息、財報/營收公告、政策或央行會議；若事件與盤面主線高度相關，必須納入主因分析。
   - 市場催化新聞優先使用當日或近 72 小時資料；超過 7 天的新聞只能作為背景，不可當作「今日主因」。公司基本面可使用最新季報、年報、法說或月營收，但必須標明資料日期。
   - 資訊蒐集以客觀證據優先：成交值、成交量、漲跌幅、產業熱度、官方公告、交易所/MOPS、財報、月營收、法說、公司新聞稿、國際通訊社與可信財經媒體。評論、傳聞、社群情緒只能輔助，不得單獨成為推薦理由。
   - 若主線與美股或國際事件有連動，必須說明連動邏輯。
   - 必須附來源連結、發布日期與證據類型，不可只憑印象。

5. 續漲導向
   - 分析假設是「今天買，今天不賣」，重點是明天到未來數日是否有延續性。
   - 避免因盤中小波動給出過短的停損或頻繁改口。
   - 防守價要分成短線失敗點與系統嚴守點，並說明使用情境。

6. 明確排序
   - 最終必須回答「今天最推薦誰」。
   - 至少給出主選、同級替代、攻擊型候選、只觀察名單。
   - 每檔要給進場區、不要追價區、防守區、預估目標價與理由。

7. 研究筆記先行
   - 在給結論前，必須先建立一份 Markdown 研究筆記。
   - 筆記檔名格式：`Reports/盤中研究筆記_YYYY-MM-DD_HHMM.md`。
   - 產出後必須重新閱讀該筆記，再根據筆記做最終選股，不可以邊想邊直接下結論。

## 最低資料量要求

每次盤中研究至少蒐集：

- 盤中掃描報表 1 份。
- 市場監控報表 1 份。
- 候選交叉排名 CSV 1 份。
- 資料庫 `scan_runs` 最新紀錄與訊號數。
- 台股即時或近即時行情抽查至少 5 檔候選股。
- 台股新聞至少 3 則，涵蓋大盤、主流族群、候選股或法人籌碼；其中至少 2 則必須是當日或近 72 小時。
- 國際新聞至少 3 則，涵蓋美股/科技股/半導體/油價/地緣政治/利率中的相關項目；其中至少 2 則必須是當日或近 72 小時。
- 本週重大事件或展會檢查至少 1 次；若有 COMPUTEX、GTC Taipei 等與台股主線高度相關的事件，必須寫入筆記。
- 候選股基本面資料至少覆蓋前 5 名。

## 新聞與資料可信度規則

1. 時效排序
   - 今日盤中、盤前、前一交易日收盤後資料優先。
   - 近 72 小時資料可作為主要催化。
   - 7 天以上資料只能當背景，除非是最新財報、月營收、法說、年報或官方公告。
   - 30 天以上一般新聞不得作為今日推薦主因。

2. 來源排序
   - 第一順位：TWSE/TPEx/MOPS、公司財報、月營收、法說簡報、公司新聞稿、官方展會/活動頁。
   - 第二順位：Reuters、Bloomberg、CNBC、Nikkei、經濟日報、工商時報、鉅亨、MoneyDJ 等具明確時間與數據的媒體。
   - 第三順位：券商報告摘要、產業媒體、專訪。
   - 第四順位：評論、社群、論壇、未具名傳聞，只能標記為市場情緒，不列入核心分數。

3. 證據類型
   - 每則重要來源必須標記為：市場數據、官方公告、財報/營收、法說/展會、國際總經、產業新聞、評論/情緒。
   - 推薦理由要以市場數據、官方公告、財報/營收、法說/展會為主；評論/情緒不得超過輔助角色。

## 最終回答格式

最終回答要先說明研究筆記路徑，再給：

- 今日主線。
- 原始三策略名單。
- 基本面加權排名。
- 主選的完整神股邏輯。
- 替代股與不選原因。
- 進場區、防守區、預估目標價。
- Telegram 是否送出。
- Git commit/push 是否完成。
